# Журнал экспериментов

Цель — сравнить классические и последовательную модели на одном разбиении,
сформировать валидный top-10 и превысить бейзлайны соревнования.
Журнал фиксирует эксперименты, для которых сохранены параметры и результаты.
Kaggle score без подтверждения не заменяется локальной метрикой.

## Постоянные условия

- Seed: 42; исходные четыре CSV без внешних данных.
- Validation: последние 20% событий каждого пользователя, округление вверх.
- Target: все отложенные оценки, без порога rating.
- Train: бинарный факт взаимодействия, без порога rating.
- Метрика: средний пользовательский Recall@10 по полному каталогу.
- Исключаем всю известную историю; выдаём 10 различных ID.
- Численные значения Kaggle и локальной валидации относятся к разным наборам и не взаимозаменяемы.

## H0. Популярность

Предположение: частоты взаимодействий дают рабочую точку отсчёта.
Считаем популярность только по train, исключаем просмотренное.

Результат: **0,036166607** локально. Отдельный Kaggle score не предоставлен.
Вывод: технический бейзлайн работает; персонализация должна сравниваться с ним.

## H1. ItemKNN

Предположение: сходство фильмов по общим пользователям улучшает персонализацию.
Cosine similarity, shrinkage = 10, до 100 соседей каждого фильма.

Результат: **0,055767496** локально; **0,0594** на Kaggle.
Вывод: результат лучше популярности, пройдены baseline_3 = 0,0195 и baseline_4 = 0,0450.
Baseline_5 = 0,0821 ещё не пройден.

## H2. EASE и регуляризация

Предположение: совместно обученные связи фильм–фильм улучшают результат ItemKNN.
Минимизируем `||X - XB||² + λ||B||²` при нулевой диагонали B.
Данные, фильтрация и target те же, что в H1. Проверено пять значений λ.

| λ | Локальный Recall@10 |
|---:|---:|
| 100 | 0,061258426 |
| 300 | 0,063335538 |
| **1000** | **0,065037745** |
| 3000 | 0,064883903 |
| 10000 | 0,062298864 |

Выбор: **λ = 1000** по validation. Локальный прирост к ItemKNN — около 16,6%.
После переобучения на всех событиях получен **Kaggle score 0,0860**, выше baseline_5 = 0,0821.
Оценка на том же validation после подбора λ может быть оптимистичной.

## H3. SASRec

Предположение: порядок и последние события пользователя содержат дополнительный сигнал.
Готовая архитектура RePlay 0.22.0; PyTorch; full cross-entropy.

| Параметр | Значение |
|---|---:|
| Максимальная длина | 100 |
| Шаг обучающих окон | 50 |
| Embedding dimension | 64 |
| Transformer blocks / heads | 2 / 2 |
| Dropout | 0,2 |
| Batch size | 128 |
| AdamW learning rate | 0,001 |
| Weight decay | 0,00001 |
| Максимум эпох / patience | 50 / 8 |
