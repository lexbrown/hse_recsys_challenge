# Checkpoints

`sasrec.pt` — финальная модель, обученная на всей доступной истории. Нужна для сабмита.
`sasrec_validation_best.pt` — лучшая модель на train-части. Нужна для воспроизведения локальной метрики.

Полный checkpoint содержит `model_state`, `parameters`, `epoch` и `item_ids`.
Новые запуски также сохраняют seed, окружение, хеши данных и признак train/full.
Порядок `item_ids` используется при декодировании рекомендаций; отдельно переиндексировать его нельзя.

Веса переносятся из исходной Kaggle-сессии или создаются командой полного обучения.
Инструкция переноса — в корневом README, раздел «Перенос уже обученных весов из Kaggle».
После импорта оба небольших `.pt` можно добавить в обычный Git.
